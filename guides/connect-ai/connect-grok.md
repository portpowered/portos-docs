# Connect Grok to Port OS

For a REST connection, follow [the authentication walkthrough](/docs/for-ai/guides/authentication-and-dcr.md), then [the REST quickstart](/docs/for-ai/guides/quickstart.md). The walkthrough covers discovery, DCR/CIMD registration, callback and tokens. To choose between REST and MCP, read [discovery and transport](/docs/for-ai/guides/oauth-discovery.md). The authorization workflow is shared across clients.

Check this client's current support for those protocols and a controlled callback. Actual client/version compatibility remains unverified until its acceptance run succeeds; a claimed client name is not a verified vendor integration.
