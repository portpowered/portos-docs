# First setup and connection verification

Use [the quickstart](/docs/for-ai/guides/quickstart.md). Check three stages separately: reachable metadata/API, a valid authenticated token, and access to the intended resources. A protocol connection alone is not device access.

Enumerate first. An empty account may need [provider linking](/docs/for-ai/guides/adding-devices.md) or a sharing grant. Select one safe test light and explain the intended command. Follow its exact schema. Read fresh state afterward; ask the user to confirm physically when no reliable observation exists. Record no passwords or tokens in conversation.

If authorization expires, refresh within the original grant or ask the user to authorize again. Confirm grant revocation in account settings or the documented revocation endpoint. See [troubleshooting](/docs/for-ai/guides/troubleshooting.md).
